# TeamFirst 운영자 매뉴얼

> 운영자(정기윤 과장)가 매칭 한 건을 처음부터 끝까지 처리하는 방법.
> 화면은 모두 `/admin/*` 경로입니다.

---

## 0. 로그인 / 계정

- 운영자 계정은 Supabase Authentication에서 생성 후 `raw_user_meta_data`에 `{"role":"admin"}`을 넣어 발급합니다.
- 로그인: `/login` → 자동으로 `/admin/dashboard`로 이동.

---

## 1. 대시보드 (`/admin/dashboard`)

상단 통계 카드로 현재 처리할 일을 한눈에 봅니다.
- **파트너 입점**: 신청 대기 / 검토·계약 중 / 입점 완료
- **매칭 진행**: 검수 대기 요청 / 진행 중 매칭 / 미팅 예정

각 카드를 클릭하면 해당 목록으로 이동합니다.

---

## 2. 파트너 입점 처리 (`/admin/partners`)

### 2-1. 신청 검토
1. `신청 대기` 탭에서 새 신청을 클릭 → 상세 진입
2. 회사 정보·매체·매칭 희망사항·첨부파일(사업자등록증/포트폴리오) 확인
3. 우측 **검토 시작** → 상태가 `검토 중`으로 변경

### 2-2. 글로싸인 계약
1. 우측 **글로싸인 계약서 등록**에 계약서 URL + 메모 입력 → 등록
2. 파트너에게 계약서 안내 메일이 자동 발송됨

### 2-3. 입점 완료 + 계정 발급
1. 계약 완료 후 **입점 완료 처리** 클릭
2. 파트너 계정이 발급되고 **임시 비밀번호가 화면에 1회만 표시**됨 (필요 시 메모)
3. 파트너에게 계정 안내 메일이 자동 발송됨

> 일괄 임포트된 계약 완료 대행사(계정 없음)는 상세 화면의 **계정 발급** 버튼으로 동일하게 발급합니다.

### 2-4. 거절
- **신청 거절** + 사유 입력 → 미선정 안내 메일 발송, 사유는 운영자 메모에 저장.

---

## 3. 매칭 요청 처리 (`/admin/requests`)

### 3-1. 요청 검수
1. `검수 대기` 탭에서 광고주 요청 클릭 → 상세 진입
2. 브랜드 정보·브리프·요청 매체·예산·광고비 증빙 확인

### 3-2. RFP 발송
1. **RFP 발송** 클릭 → 입점 완료 대행사 **전원**에게 `rfp_notifications` 생성
2. n8n 워크플로우(슬라이드 생성·메일)가 자동 트리거됨
3. 상태가 `RFP 발송됨`으로 변경. 필요 시 **지원 수집 단계로 전환**

### 3-3. 상위 3개사 선정 (점수표)
1. 지원 대행사 목록에서 최대 3개사 체크
2. 각 후보의 **6개 항목 점수**(규모/퍼포먼스/기술·분석/커뮤니케이션/레퍼런스/적합도, 각 0~10) 입력
3. 추천 사유 작성 → **후보 확정 및 광고주에게 전달**
4. 선정사에는 선정 안내, 미선정사에는 미선정 안내 메일이 자동 발송됨

### 3-4. 대행 결정
- 미팅 후 후보 중 1곳을 **이 대행사로 성사** → 요청 마감(closed_won), 성사사에 안내 메일
- 무산 시 **대행 불발로 마감**(closed_lost)

---

## 4. 미팅 관리 (`/admin/meetings`)

- 광고주가 일정 제안 → 대행사 수락 시 자동으로 목록에 표시
- **구글미트 링크 등록**: 확정된 미팅에 링크 입력 (미팅 2~3일 전 권장)
- **미팅 완료 처리**
- **D-7 데드라인 카운터**: 미팅 후 대행 결정 기한. D-2 이하 빨간색 경고

---

## 5. 자주 묻는 운영 이슈

| 상황 | 조치 |
|---|---|
| 메일이 안 나감 | Resend 도메인 인증 상태 + `RESEND_*` 환경변수 확인. 미설정 시 발송은 조용히 건너뜀(흐름은 정상) |
| RFP 슬라이드가 자동 생성 안 됨 | n8n 워크플로우의 Webhook 노드 + `N8N_WEBHOOK_URL` 환경변수 확인 |
| 파트너가 로그인 못 함 | 상세 화면에서 계정 발급 여부 확인. 미발급 시 **계정 발급** |
| 광고비 증빙이 안 보임 | 광고주가 요청 단계에서 업로드했는지 확인. 다운로드 링크는 10분 유효 |

---

## 5b. 마케터 매칭 (Phase 2)

### 마케터 등록·공개
- `/admin/marketers` → **+ 마케터 등록**
- 분야(퍼포먼스/그로스/브랜드/콘텐츠), 한 줄 소개, 상세, 스킬, 포트폴리오(`제목 | URL` 한 줄씩) 입력
- **공개(published)** 토글 ON → `/marketers` 로스터 + `/marketers/[slug]` 노출
- 목록의 `공개/비공개` 칩 클릭으로 즉시 토글

### 마케터 로그인 계정 발급 (선택)
- 마케터 편집 화면에서 **이메일** 입력·저장 → **"계정 발급"** 버튼
- 임시 비밀번호 + 안내 메일 자동 발송. 첫 로그인 시 비번 변경 강제
- 마케터는 `/marketer-console`에서 제안받은 매칭·인터뷰·본인 프로필 확인

### 마케터 매칭 신청 처리
- `/admin/marketer-requests`에서 브랜드 신청 확인
- **관리** 화면에서:
  - **상태**: 접수 → 검토 → 마케터 제안 → 인터뷰 → 확정 → 종료
  - **제안 마케터** 드롭다운(공개 마케터만)
  - **인터뷰 일시** (datetime-local)
  - **운영 메모**
- 저장 시 광고주 `/client/marketer-requests`에도 즉시 반영

### 사례(케이스) CMS
- `/admin/cases` → **+ 사례 작성**
- 브랜드명/업종/요약/본문/성과 지표(`지표명 | 값` 한 줄씩)/커버 이미지 URL
- 공개 토글 → `/cases` + `/cases/[slug]` 노출

---

## 6. 라이프사이클 한눈에

```
[입점] 신청 → 검토 시작 → 글로싸인 계약 등록 → 입점 완료+계정 발급
[매칭] 요청 검수 → RFP 발송 → 지원 수집 → 상위 3개사 선정(점수표) → 광고주 전달
[제안] 광고주 후보 확인 → 관심 표시 → 분석권한 부여 → 광고비 업로드
[미팅] 광고주 일정 제안 → 대행사 수락 → 구글미트 링크 → 미팅
[결정] 대행 성사/불발 → 요청 마감
```
